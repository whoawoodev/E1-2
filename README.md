# 이산수학 기초 퀴즈 게임

터미널에서 동작하는 파이썬 콘솔 퀴즈 게임입니다.
문제를 풀고, 직접 문제를 등록하고, 최고 점수를 기록합니다.
프로그램을 껐다 켜도 추가한 퀴즈와 최고 점수가 그대로 남습니다.

## 퀴즈 주제와 선정 이유

주제는 **이산수학 기초**입니다.

컴퓨터공학 과정에서 배우고 있는 내용이라 정답뿐 아니라 왜 그 답이 되는지까지
스스로 설명할 수 있었습니다. 명제, 집합, 진리표처럼 답이 하나로 정해지는 개념이 많아
선택지 4개 중 하나를 고르는 형식과도 잘 맞았습니다.

오답 선택지를 아무 값으로나 채우지 않고, 역·이·대우를 헷갈리거나
부분집합 개수를 2^n 대신 n^2로 세는 것처럼 실제로 틀리기 쉬운 지점을 넣었습니다.

## 실행 방법

Python 3.10 이상이 필요하며, 외부 라이브러리는 쓰지 않습니다.

```bash
git clone https://github.com/whoawoodev/E1-2.git
cd E1-2
python3 main.py
```

## 기능 목록

| 메뉴 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 퀴즈 풀기 | 풀 문제 수를 고르면 무작위 순서로 출제하고, 점수를 계산해 최고 점수와 기록을 남깁니다. |
| 2 | 퀴즈 추가 | 문제·선택지 4개·정답 번호·힌트를 입력받아 목록에 넣고 바로 저장합니다. |
| 3 | 퀴즈 목록 | 등록된 문제를 번호와 함께 보여줍니다. |
| 4 | 점수 확인 | 최고 점수와 최근 게임 기록 5개를 보여줍니다. |
| 5 | 퀴즈 삭제 | 번호를 골라 퀴즈를 지웁니다. 0을 누르면 취소합니다. |
| 6 | 종료 | 저장한 뒤 프로그램을 끝냅니다. |

### 선택 구현 기능

- **무작위 출제** — `random.sample()`로 매번 다른 순서로 출제합니다.
- **문제 수 선택** — 등록된 문제 수 안에서 몇 문제를 풀지 고를 수 있습니다.
- **힌트** — 정답 대신 `0`을 누르면 힌트가 나옵니다. 한 번당 5점이 깎이고,
  같은 문제에서 여러 번 눌러도 한 번만 계산합니다. 힌트가 없는 문제는 차감하지 않습니다.
- **퀴즈 삭제** — 목록에서 번호를 골라 지우고 파일에 반영합니다.
- **점수 기록** — 게임이 끝날 때마다 날짜·시각, 푼 문제 수, 점수를 남깁니다.

### 입력 처리 기준

- 입력값의 앞뒤 공백을 제거한 뒤 처리합니다. (` 1 ` → `1`)
- 숫자가 아닌 값, 허용 범위 밖의 숫자, 빈 입력은 안내 메시지를 출력하고 다시 묻습니다.
- `Ctrl+C`나 입력 스트림 종료로 중단되어도 데이터를 저장하고 정상적으로 끝냅니다.
- `state.json`이 없으면 기본 퀴즈로 시작하고, 파일이 손상된 경우 안내 후 기본 퀴즈로 복구합니다.

## 파일 구조

```
E1-2/
├── main.py         프로그램 시작점. 실행 중단(Ctrl+C, EOF)을 받아 안전하게 종료
├── quiz_game.py    QuizGame 클래스와 공통 입력 함수(ask_number, ask_text)
├── quiz.py         Quiz 클래스. 문제 하나의 출력과 정답 확인을 담당
├── storage.py      기본 퀴즈 데이터와 state.json 읽기/쓰기
├── state.json      실행 중 생성되는 데이터 파일 (아래 설명)
├── .gitignore      파이썬 표준 템플릿 + state.json
└── README.md
```

역할을 나눈 기준은 **바뀌는 이유가 다른 코드를 같은 파일에 두지 않는 것**입니다.
문제의 형태가 바뀌면 `quiz.py`, 저장 방식이 바뀌면 `storage.py`,
화면 흐름이 바뀌면 `quiz_game.py`만 고치면 됩니다.

파일 이름은 클래스가 들어 있으면 클래스명을 그대로 따랐고(`Quiz` → `quiz.py`,
`QuizGame` → `quiz_game.py`), 클래스가 없는 파일은 역할 이름을 썼습니다(`storage.py`, `main.py`).

## 데이터 파일 설명 (state.json)

- **경로**: 프로젝트 루트의 `state.json` (`storage.py`에서 실행 위치와 무관하게 절대경로로 지정)
- **인코딩**: UTF-8 (`ensure_ascii=False`로 한글을 그대로 저장)
- **생성 시점**: 첫 실행에서 퀴즈를 풀거나 추가하거나 종료할 때 만들어집니다.
- **없을 때**: `storage.make_default_quizzes()`의 기본 6문항으로 시작합니다.

### 스키마

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `quizzes` | list | 퀴즈 목록 |
| `quizzes[].question` | str | 문제 문장 |
| `quizzes[].choices` | list(str) | 선택지 4개 |
| `quizzes[].answer` | int | 정답 번호 (1\~4) |
| `quizzes[].hint` | str | 힌트 문장. 없으면 빈 문자열 |
| `best_score` | int | 최고 점수 (0\~100). 정답 수 ÷ 푼 문제 수 × 100에서 힌트 차감분을 뺀 값 |
| `history` | list | 게임 기록 목록 |
| `history[].played_at` | str | 플레이 시각 (`YYYY-MM-DD HH:MM`) |
| `history[].count` | int | 그 판에서 푼 문제 수 |
| `history[].score` | int | 그 판의 최종 점수 |

```json
{
  "quizzes": [
    {
      "question": "원소가 3개인 집합의 부분집합은 모두 몇 개인가?",
      "choices": ["3개", "6개", "8개", "9개"],
      "answer": 3,
      "hint": "원소마다 넣는다/안 넣는다 두 가지 선택이 있습니다."
    }
  ],
  "best_score": 83,
  "history": [
    { "played_at": "2026-08-21 09:14", "count": 6, "score": 83 }
  ]
}
```

점수를 정답 개수가 아니라 백분율로 저장한 이유는, 퀴즈를 추가할 수 있고 풀 문제 수도
고를 수 있기 때문입니다. 개수로 두면 6문제 중 5개와 10문제 중 5개가 같은 값이 되어
비교가 되지 않습니다.

`hint` 필드는 나중에 추가한 항목이라, 이 필드가 없는 예전 저장 파일도 읽을 수 있도록
`data.get("hint", "")`으로 기본값을 주었습니다. `history`도 같은 방식입니다.
